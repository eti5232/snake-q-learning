# נחש שלומד לבד (Q-learning)

פרויקט לימודי קטן: נחש שמלמד את עצמו לשחק, בלי ספריות חיצוניות ובלי כרטיס מסך.
האימון לוקח כ-3 שניות על מעבד רגיל.

## הרצה

דורש Python 3.10 ומעלה. אין מה להתקין (החלון משתמש ב-`tkinter` שמגיע עם Python).

```bash
python main.py train   # אימון מהיר בלי חלון, שומר את "המוח" לקובץ
python main.py watch   # צפייה בנחש המאומן משחק
python main.py learn   # צפייה בנחש לומד מאפס, בזמן אמת (נשמר בסגירת החלון)
```

ב-`learn` אפשר להזיז את המחוגה **Speed**. במהירות 1 רואים כל צעד, ובמהירות גבוהה רואים את הגרף עולה.
בהתחלה הנחש כמעט אקראי (`epsilon` גבוה), ולאט לאט הוא סומך יותר על מה שלמד.

## איך הוא לומד

הנחש לא רואה את כל הלוח. בכל רגע הוא מקבל 8 מספרים בלבד (ה"מצב"):

| מספרים | משמעות |
|---|---|
| 3 | יש סכנה (הגוף של הנחש עצמו) ישר / ימינה / שמאלה? |
| 1 | לאן הוא פונה (למעלה, ימינה, למטה, שמאלה) |
| 4 | האוכל נמצא למעלה / ימינה / למטה / שמאלה ממנו? (בדרך הקצרה, גם דרך הקצה) |

**חוקי המשחק:** אין קירות קטלניים. מי שיוצא מצד אחד של הלוח נכנס מהצד הנגדי, וגם הפינות לא מסוכנות.
הנחש מת רק כשהוא נוגע בגוף של עצמו, או כשהוא מסתובב יותר מדי זמן בלי לאכול.

לכל מצב יש שורה בטבלה עם 3 ציונים: ישר, פנייה ימינה, פנייה שמאלה.
אחרי כל צעד הציון של הפעולה שנבחרה מתקרב ל:

```
פרס מיידי + 0.9 * (הציון הכי טוב במצב הבא)
```

פרסים: אוכל `+10`, מוות `-10`, התקרבות לאוכל `+0.1`, התרחקות `-0.15`.
את כל המספרים אפשר לשנות ב-[config.py](config.py).

הטבלה כולה היא קובץ JSON קריא: [models/snake_brain.json](models/snake_brain.json).
אפשר לפתוח אותו ולראות מה הנחש "חושב" בכל מצב.

## ידידותי לסביבה

- **בלי רשת נוירונים.** טבלה של כמה מאות שורות במקום מיליוני משקלים, ולכן מספיק מעבד אחד ואין צורך ב-GPU או TPU.
- **בלי תלויות.** אין התקנות, אין הורדות כבדות.
- **עצירה מוקדמת.** האימון נעצר כשהממוצע מפסיק להשתפר (`patience_episodes`), ואפשר להגביל זמן עם `--max-seconds`.
- **מאמנים פעם אחת.** המוח נשמר ו-`watch` רק טוען אותו, בלי אימון מחדש.
- **ציור חסכוני.** בחלון מצוירת רק התמונה האחרונה בכל פריים, ולכן מהירות גבוהה לא מכבידה על המחשב.
- **אימון בלי חלון.** `train` לא טוען את ספריית הגרפיקה, ולכן אפשר להריץ אותו גם על שרת.

## רעיונות להמשך

- להגדיל את `grid_size` ולראות כמה האימון מתארך.
- להוסיף לנחש "ראייה" רחוקה יותר (סכנה במרחק 2 משבצות) ולבדוק אם הציון משתפר.
- לשנות את הפרסים ולראות איך ההתנהגות משתנה.
